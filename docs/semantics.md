## 1. Принципы

1. **Один кластер = одно намерение = одна посадочная.** Фраза не может жить на двух страницах; пересечения помечены кросс-ссылкой. Урок конкурента: два URL под одно намерение (у mostransneft два лендинга под ДГУ) каннибализируют друг друга.
2. **Частотности не выдумываем.** Во всех таблицах колонка «Частотность» = «— (Вордстат)». Реальные цифры снимает владелец по инструкции из раздела 5 (15 минут) или студия при доступе к Вордстату. До этого приоритизация — по колонке «Приоритет»:
   - **P1** — близко к сделке, ядро запуска (коммерческие «купить/доставка/с НДС», горячие сегменты, срочность, бренд);
   - **P2** — коммерческий потенциал есть, но сезонность/меньшая ёмкость/вторая волна (гео-города, сезонные марки вне сезона, оборудование);
   - **P3** — прогрев и поддержка (инфо-запросы, сервисные услуги, тендеры).
3. **Ограничения анкеты действуют на уровне ядра:**
   - цену НЕ публикуем нигде (сайт, объявления, мета-теги). Цена-запросы в ядре остаются — они горячие; посадочная отвечает формой предварительного расчёта (параметры → письмо менеджеру на email; цифра на экране НЕ показывается) + «окончательную цену подтверждает менеджер». В title/description таких страниц — «рассчитайте стоимость», а не «цена N руб.»;
   - НЕ обещаем «самая низкая цена» — фразы вида «самое дешёвое топливо» в ядро не берём;
   - минимальный объём 500 л, максимум 30 000 л — запросы про канистры/бочки 200 л уходят в минус;
   - марки только реально поставляемые: летнее / межсезонное / зимнее (сорт C / сорт E / сорт F, ДТ-Л/ДТ-З, Евро-5, −15/−25/−35). Арктическое ДТ, печное топливо, керосин, бензин, СМТ — не заявлены в анкете → минус-лист и открытые вопросы;
   - «солярка» подтверждена анкетой как слово клиентов; опечатка «салярка» — отдельный список только для Директа (на сайте слово с опечаткой не пишем).
4. **Фразы построены морфологически** из формулировок анкеты, seo-plan v1 и SERP-данных конкурентного отчёта. Это стартовое ядро для посадочных и Директа; после съёма Вордстата список пополняется хвостами из левой колонки, а нулевые фразы вычищаются.
5. **Гео-страницы — только с реальным контентом** (зона, срок, ограничение по расстоянию из анкеты): шаблон «город + подмена слова» не делаем — это прямой урок из разбора поддоменов конкурента.

## 5. Что снять в Вордстате (инструкция владельцу, ~15 минут)

Зачем: в этом документе частотности не выдуманы — их нет. 15 минут в Вордстате превращают приоритеты P1/P2/P3 в план с цифрами и решают судьбу гео-страниц и «срочной» посадочной.

Как: открыть `wordstat.yandex.ru` → войти в Яндекс-аккаунт → справа выбрать регион **«Москва и область»** (не «Россия»!) → вбивать маски по одной, делать скриншот или выписывать число показов. Смотреть обе колонки: левая (что искали с этим словом) — источник хвостов для пополнения ядра, правая (похожие запросы) — проверка, не упущен ли кластер.

Маски (по одной, ~40 сек на маску):

1. `дизельное топливо` — общий объём ниши и хвосты
2. `купить дизельное топливо`
3. `доставка дизельного топлива`
4. `дизтопливо`
5. `солярка` — заодно видно долю «салярка» в левой колонке
6. `салярка` — точный объём опечатки для Директа
7. `зимнее дизельное топливо` — снять в конце августа и повторно в октябре (сезон растёт)
8. `дизельное топливо с ндс`
9. `топливо для генератора`
10. `топливо для котельной`
11. `дизельное топливо для дома` и `солярка для отопления`
12. `мини азс`, `еврокуб для топлива`
13. `доставка дизельного топлива подольск` (и ещё 4–5 городов из таблицы 3.22 на выбор) — решение, какие гео-страницы делать первыми
14. `срочно дизтопливо` и `дизтопливо круглосуточно` — нужна ли отдельная «срочная» посадочная
15. `мос дизель`, `дтснаб` — есть ли уже брендовый спрос; для сравнения `мостранснефть` (бренд-бенчмарк конкурента)

Дальше мы: подтверждаем/понижаем приоритеты, выбираем первые 5 гео-городов, пополняем ядро хвостами, собираем из этого же материала прогноз бюджета Директа (Прогноз бюджета Яндекса — отдельные 10 минут, маски те же).
