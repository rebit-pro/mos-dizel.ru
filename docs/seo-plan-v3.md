### 2.4. Требования к гео-страницам (кластер 22) и странице регионов (кластер 39)

Гео-города МО — как в v2: публикуем только с уникальным контентом — реальная зона и срок для города, ограничение по расстоянию, ближайший маршрут от базы (Люберецкий р-н), примеры поставок в направлении (когда появятся честные кейсы). Первая — Люберцы (база компании). Следующие 4–6 городов — строго по Вордстату (маска 13 semantics §5) и подтверждённой логистике. Шаблон «город + замена слова» запрещён — прямой урок из разбора поддоменов конкурента.

Страница регионов `/dostavka-dizelnogo-topliva-v-regiony/` — новое в v3:
- **Честный список областей** — целиком или в основном в радиусе 400 км от МКАД: Тверская, Ярославская, Владимирская, Рязанская, Тульская, Калужская, Смоленская, Ивановская, Орловская, Брянская, Костромская. Нижегородская, Липецкая и Новгородская области входят в радиус лишь частично (ближние к Москве районы) — на старте не перечисляем; добавляем поштучно после первых поставок.
- **Без «день в день»**: для регионов клиент срок не подтвердил — везде «срок согласуем при расчёте». Ночные рейсы в регионы не обещаем.
- **Без отдельных URL по областям** до съёма масок «доставка дизтоплива тверь / ярославль / владимир / рязань / тула / калуга» (§9 п. 16). Если спрос подтвердится — страницы по областям создаются по тем же правилам, что гео-города: реальная зона, срок, маршрут; никакого шаблона.
- Структура: H1 → карта/список областей с расстоянием от МКАД (по дорогам — снять по Яндекс Картам, не выдумывать) → объёмы (500–30 000 л; для дальних адресов минимальный объём может быть выше — «уточнит менеджер») → документы → сельхозтехника и котельные как типовые заказчики регионов (ссылки) → FAQ (сколько ехать; минимальный объём в область; кто платит за перегон — «включаем в расчёт, без отдельных тарифов на сайте»).
- Ссылки на страницу: `#fleet` лендинга (строка географии), `/dostavka-dizelnogo-topliva/`, `/dostavka-dizelnogo-topliva-moskovskaya-oblast/`, `/toplivo-dlya-selhoztehniki/`. Директ П8 «Регионы до 400 км» ведёт сюда (direct-plan v2).

3. ⚠ Доступ к DNS клиент не подтвердил (client-answers 3.8). Если доступа нет к 21.09 — на Tilda-странице dtcnab.ru ставим canonical на `https://mos-dizel.ru/` и баннер переезда; это не 301 — вернуться к п. 1 сразу после доступа. **Релиз W0 из-за этого не переносится.**

### 6.2. Цели — на все точки контакта (изменено: без мессенджеров)

Единая таблица целей для SEO и Директа — direct-plan v2 §6.1 ссылается сюда; id зафиксированы и не меняются (по агрегату `lead` учатся автостратегии Директа). `calc_start` из direct-plan v1 = `form_start` (в коде одно имя). Цели «показ расчёта на экране» нет: форма экранного результата не выводит.
